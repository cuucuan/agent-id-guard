2 · Self-audit your approvals

Pick a token you hold. We read its allowance for well-known spenders and flag unlimited approvals — the kind that can drain a wallet if a spender is ever compromised. This is read-only: nothing is signed, nothing is sent.

How it works

  1. Hold an Agent ID. The Guard Pass contract reads the Agent ID registry (0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F) and only mints when your wallet's balance is above zero.
  2. Mint free. mint() is non-payable — the contract itself enforces value 0. You pay only the network gas.
  3. Keep the pass. It's soulbound: transfers revert in the contract, so the pass always proves the wallet that earned it.
  4. Audit yourself. The approval check above runs entirely in your browser against public chain data. Agent ID is used as an access gate only — never to look up anyone else's wallet.
